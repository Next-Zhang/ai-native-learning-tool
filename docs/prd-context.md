## 2. 状态标记（v2.1 五档）与旧标记映射

| 标记 | 含义 | 本项目使用约定 |
|---|---|---|
| **已验证** | 有可回溯证据或测试结果 | 必须附证据（测试结果、运行记录、会话数据） |
| **待验证** | 本阶段必须考虑，但结论尚无证据 | 写假设 + 验证方法 + 判断标准 + 负责人 + 阻塞节点 |
| **待定** | 已识别决策或外部确认事项 | 写可选方案、阻塞节点、决策人、期限 |
| **暂缓** | 可能适用，但当前阶段无需决策 | 写阶段理由 + 重评触发；**不可暂缓安全或发布门槛** |
| **不适用** | 当前能力或实际用途不触发 | 写事实理由 + 能力变化后的重评条件 |

> 旧标记映射：🔶 假设 → **待验证**；🔵 待定 → **待定**（本文件后文统一用 v2.1 五档）。
> 纪律：**"已实现" ≠ "已验证"**；实现完成不代表达到质量门槛。

## 3. 模块开关判定（v2.1 §0.3）

| 判断项 | 本项目 | 结论 |
|---|---|---|
| 生成开放式内容？ | **是**（教学解释、学习计划、测评题、验收反馈） | ✅ 启用 **A 生成式输出** |
| 依赖外部资料/检索？ | 本期**否**（不建 RAG；改用联网检索**工具**） | ⚪ **B 不适用（本期）**：外部信息经工具调用获取，未经自建索引；能力变化后重评 |
| 调用工具/自主决定步骤？ | **是**（联网检索 + 状态机决策推进） | ✅ 启用 **C 工具、工作流与 Agent** |
| 保留跨会话记忆/画像？ | **是**（画像、计划、进度、记忆策略） | ✅ 启用 **D 记忆与个性化** |
| 输出评分/排序/预测？ | **是**（题目判定、掌握度评分、薄弱点排序） | ✅ 启用 **E 决策与预测**（须写错误代价、分层评估、解释与申诉） |
| 多模态？ | 否（纯文本） | ⚪ **F 不适用** + 重评条件 |
| 训练/微调自有模型？ | 否（仅调用 API + 本地 embedding） | ⚪ **G 不适用** + 重评条件 |
| 高影响场景？ | **待核**：AI 输出学习评估结论并据以调整学习路径（教育场景） | ⚠️ **H 高影响场景 = 待核**：按 §15.1 做适用性审查，**不得因"个人项目"直接写不适用** |
| 对外开放 API？ | 否（本期仅自用 + 演示） | ⚪ **I 不适用** + 重评条件 |

**适用性结论**：启用 **A / C / D / E**，**H 待核**；B / F / G / I 写"不适用 + 理由 + 重评触发"。

## 4. 个人项目模式落地（v2.1 §0.5）

**启用条件**：由个人负责、目标是验证具体用户问题与最小可行方案、尚未承诺规模化 → **满足**。
**本轮决策**：**开始开发**（继续实现 MVP）。项目阶段记为"**开发中**"。

| 模板位置 | 本项目最低填写方式 | 可暂缓内容与重评触发 |
|---|---|---|
| §4 战略关系 | 写**个人项目目标**：验证"验收式学习"是否有效、形成可展示的 AI 产品作品；说明通用大模型与课程平台的缺口 | 组织战略、市场规模；准备商业化或争取组织资源时重评 |
| §4 商业模式 | 标 **"暂缓：本阶段不验证商业化"**，说明实际成本（API + 本机算力）与预算上限（**待测基线后填**） | 收费、获客、收入预测；决定收费时重评 |
| §5 计划与角色 | 一人兼任所有角色；写实际里程碑、P0 范围与顺序 | 多角色排期、远期版本计划；协作或交付承诺增加时重评 |
| §8–§10 成效与评测 | 设一个可观察任务结果（7 天计划完成率）、先测基线、少量代表性场景 + 关键失败用例；**写样本局限**；保留**独立验收集**原则 | 大规模 A/B、复杂统计；样本量与发布范围扩大时深化 |
| §14 运维 | 写 API 预算上限、基本故障处理、停用方式；**说明数据去向（仅本机）** | 容量规划、SLA/SLO、多环境运维；对外持续服务时重评 |
| §15 评审 | 一人记录"证据→结论→下一步"；关键风险邀请试用者复核 | 多部门签署；进入组织协作/合同交付/公开发布时重评 |

**红线（v2.1 明确）**：**不得**把尚未证实的**用户价值、AI 质量、必要的数据处理、关键安全风险**写成"不适用"。
→ 直接约束我们：§9（AI 与系统质量）与 §13（失败/安全/风险）**必须实写**——这正是"五维质量体系"的落点。

**阶段出口**：在 §15 记录一轮试用/评测后的证据、样本限制、P0 阻断项与"继续 / 缩小范围 / 调整 / 停止"决定；**原型通过 ≠ 可公开发布**。
