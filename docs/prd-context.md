## 6. 成功指标（Context Q6 + 追加要求）
- **首要指标：7 天滚动计划完成率**（用户层、可自动测量、自用也能测）
- 拟配：次要=首次验收通过率、平均澄清轮数；护栏=单轮成本、P95 延迟、幻觉抽样率
- **追加要求：建立五维评测指标体系**
  | 维度 | 关注点 | 示例指标 |
  |---|---|---|
  | D1 AI 能力 | 模型/Agent 行为质量 | 阶段路由准确率、抽取准确率、判分一致率、工具调用正确率、groundedness |
  | D2 软件工程 | 确定性逻辑与可靠性 | 73 测试通过率、端到端链路成功率、API 错误/超时、崩溃恢复率 |
  | D3 用户价值 | 真实学习效果 | **7 天计划完成率（首要）**、首次验收通过率、澄清轮数 |
  | D4 成本与性能（横切） | 经济性与速度 | 单轮 token 成本、P95 延迟、**平均每轮 LLM 调用次数**、检索缓存命中率 |
  | D5 安全与合规（横切） | 攻击面与数据权利 | 注入拦截率、越权拦截率、PII 泄漏事件数 |
- **架构要求**：初期就要**保留指标数据采集与导出接口**（本地优先 JSONL/SQLite + `python -m metrics.export --format csv`），便于产品迭代做数据分析；**不做**实时看板

## 10. 差异化定位（Context Q10 = 1 + 2）
| 替代方案 | 其强项 | 缺口（我们的机会） |
|---|---|---|
| 通用大模型（ChatGPT/Claude/DeepSeek） | 能答、知识广、随时可用 | 能答 ≠ 会教：不记画像、无滚动计划、**不验收**、不安排复习 |
| 课程/教程平台 + 自己排计划 | 内容权威、体系完整 | 计划是通用模板、不按水平/预算滚动；**学完无人验收**；进度靠自律 |
| **我们** | —— | **状态驱动的验收式学习** + **领域可插拔** |

⚠️ 诚实标注：**无 RAG → 内容权威性弱于课程平台**（写进 §9/§11 作为取舍与风险）
