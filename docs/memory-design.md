# 当前记忆子系统

核对：2026-10-13；2026-10-14 补充专项审查。本文描述当前记忆实现；产品连续性要求见 [PRD](PRD.md)，差距见 [交付清单](delivery.md)。
目标架构已明确为 Way 作用域下的四模块，见 [目标记忆架构](memory-architecture.md)。本页仍描述现有实现，Router、任务级读取与生命周期管理尚未接入。
原设计与参数演进见 [历史快照](archive/2026-10-13/memory-design-v0.18.md)。
产品统一称“学习会话”，与代码 session_seq 的“计划学习序号”区分；详见 [术语表](terminology.md)。本文仍描述当前实现，不把序号推进等同实际返回学习。

## 1. 对象与边界

2026-10-14 范围澄清：本期只做单学习路径（Way）；后续保留多个 Way、单个激活及路径间记忆隔离另行实现，见 PRD 第 4.3 节。当前单文件记忆不因此被描述为已支持多路径。

| 概念 | 当前代码含义 |
|---|---|
| 对话轮 | 一次 run_turn |
| 计划单元 | current_window.days[i]，包含多个任务 |
| 学习序号 | session_seq，随游标跨计划单元前进 |
| 实际学习会话 | 当前未独立建模；不能由计划单元或 CLI 启动次数直接等同 |

持续学习需要实际中断后接续；计划序号并不证明真实用户回访。

## 2. 长期事实与派生视图

evidence 按知识点文本保存来源、时间、session_seq、判定、分数、错误和 task_id。
测评 finalize 与验收 apply_update 写证据；derive_profile 回放得出 skill_profile，薄弱点与待复验由规则派生。
来源含 assessment、evaluation、迁移来源及降采样 summary 锚点；锚点不是一次新测量。

每个知识点保留最近 K 条；超出部分回放为锚点，保留累计分数语义，但不保留全部早期错误与任务明细。
知识点文本与 task_id 的稳定性存在 D-11；测评失败写零分存在 D-02。不能宣传为无损且完全可信的事实库。

## 3. 叙事与注入

- rolling_summary：本计划单元内滚动摘要。
- session_summaries：已定稿摘要；session_records 保存单元记录。
- conversation_history：近期原文。
- conversation_archive：按序号分段的历史原文，可由确定性函数回取；不默认全部注入。

对话先放阶段提示词和可选资料，再放摘要、最近原文，最后放权威状态和本轮输入。
历史选择按字符预算并保留最少原文消息；字符预算不是 token 上限，也不是整个请求的绝对硬上限。
长用户输入、任务与固定内容仍可能超过预算；不能据此宣称上下文长度完全固定。

L1 将超量历史压成滚动摘要；L2 在已完成单元待定稿时生成摘要。
L2 采用代码骨架加模型润色，短语护栏拦截部分判定性词汇；L1 直接接收润色结果，没有同样的内容检查。模型失败时 L1 保留旧摘要或骨架，L2 回退骨架；骨架在前不能阻止补充段编造过程事实。
摘要用于接续过程，不写掌握结论；当前护栏效果仍需真实模型验证。

## 5. 存储、回取与清理

数据存于 user_state.json；zones.py 提供逻辑归属，不实施运行时写隔离。
原文与摘要有配置的保留上限，但实际路径不完全执行：L1 归档不调用裁剪，session_records 重复保存摘要且无裁剪。不能声明整体存储已严格有界；证据降采样仍减少早期明细。
evidence_for、archive_segments 等可由代码回取，但没有根据任务自动找回旧原文的链路、稳定消息引用或完整查询界面。

/reset 当前清近期原文与归档，仍保留摘要，后续继续注入（D-03）。
/reset all 重置状态并保留旧备份；metrics 和 trace 独立存在，trace 含输入及回复。
“重置学习进度”“清除对话记忆”“彻底删除数据”需分别定义，当前不能互相替代。
本期不新增三个清理入口，只规范并修复已有操作：清对话需连叙事摘要一起清，完全重置明确保留备份/日志；彻底删除提供手动范围说明。以上为目标要求，D-03 与 D-08 尚未修复。

## 6. 实现与验证边界

证据、两级摘要、保留函数与待复验提示已存在；真实跨会话接续、完整复验及学习收益尚未得到充分验证。
程序故障不应成为用户能力证据；在修复 D-02 前，长期画像存在污染路径。
2026-10-14 纯内存专项复现确认：L1 接受判定性摘要；L2 未接收旧滚动接续信息便清空；L1 输入截断但整批原文移走；归档可超过配置上限；session_records 不随摘要裁剪；L2 补充可引入不存在的过程事实。详见 D-13～18 和验证报告。
