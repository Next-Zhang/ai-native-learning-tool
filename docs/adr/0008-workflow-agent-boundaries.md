# ADR-008：拆分 Workflow、Agent 与产品数据所有权

2026-11-01，项目负责人明确长期目标为多人在线产品，并要求拆出 Workflow 与 Agent 设计。产品六部分主框架保留为系统职责视图，Workflow 维护业务依赖/授权/确认，Agent 在允许范围内通过反馈循环选择行动，学习能力与数据服务执行并维护各自权威记录。

本决策细化 ADR-006 的受约束自主选择，不取消 1.0 首先局部开放 ReAct 的交付策略。部分替代 ADR-007 将业务证据、资料、运行检查点和上下文一并归入记忆总入口的范围；记忆 Router/存储/生命周期继续管理狭义记忆，上下文成为跨数据服务的独立读取能力。

当前仍交付单用户本机单 Way；接口携带可信主体与作用域，为未来在线演进提供边界，但不提前建设账号、多租户或队列。JSON 仅是本地适配器，不能作为多人并发的既定存储方案。Python 核心保留，界面通过应用服务交互。

设计见 [产品系统设计](../system-design.md)、[Workflow](../workflow-design.md)、[Agent 运行](../agent-runtime-design.md)。旧记忆开发规格保留来源/版本/恢复等机制参考，涉及总入口、数据归属和在线存储部分须按本决策修订后再开发。本次仅更新文档。
