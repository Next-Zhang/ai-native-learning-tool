# ADR-007：Way 作用域下的四模块记忆管理

2026-10-14，项目负责人确认以当前学习目标对应的 Way 为主要作用域，记忆管理分为 Router、存储、上下文组装与注入、生命周期管理。与统一聊天摘要或模型自由写记忆相比，这一选择将写入资格、可靠存储、任务相关读取和清理规则分别管理，避免摘要升级为证据或旧记忆无界积累；目标设计尚未实现。

Router 负责分类和准入，业务状态仍按系统规则更新；读取先限定 Way 和有效版本，原文通过稳定引用回取；生命周期按用途、有效性、依赖和可替代性清理。学习证据与叙事、ReAct 工作记忆、评估记录分别管理。1.0 只实现单 Way，可继续使用 JSON，不引入多路径框架或新数据库。

本决策补充 ADR-004 的证据/叙事分工及 ADR-005 的存储取舍，部分替代早先 O-06 将现有策略视为唯一目标设计的表述；不改变本期不新增清理入口和实测后调参的边界。旧保留参数不授权永久保留或无视新用途，具体类型保留条件及实现机制见 [目标记忆架构](../memory-architecture.md)。调用/检索评估另行设计，清理临时记忆不抹去其评估事件。

实现细节已由项目负责人委托设计，见 [开发规格](../memory-implementation-spec.md)。统一协调入口已确认，工程选择为单文件版本提交、确定性准入、可引用来源摘要、按任务组装与依赖清理；尚未实施。
