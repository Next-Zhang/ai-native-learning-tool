# ADR-009：产品数据管理与领域 Router

2026-11-01，项目负责人要求将产品层数据管理重新命名，区分 Agent 可读和不可读的数据，并按领域设置 Router，Agent 存取都必须经判断。产品系统层采用“产品数据管理与访问层”；偏好、对话和接续摘要采用“用户与会话数据服务”，不再用“Agent 长期记忆”代表数据仓库。

学习业务、证据、用户/会话、资料、运行、评估、身份策略各有领域 Router；统一入口仅分发，领域所有者维护规则。读取在访问前限制主体、Way、用途与字段，写入经来源、版本和授权校验后执行领域命令。上下文预加载、缓存、搜索和工具观察同样受约束，Agent 不拥有直连存储能力。

此决策细化 ADR-008，不新增数据库或微服务；单机原型和在线演进的阶段边界不变。数据权限矩阵见 [产品数据管理与访问设计](../data-access-design.md)，实现与验证尚未执行。
