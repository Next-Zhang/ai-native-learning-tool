# 产品 Workflow 设计

> 当前交付范围：GitHub 下载源码后本地运行的初版软件，不涉及多人线上运行。后端具体契约与工程默认值见 [本地后端设计](backend-design.md)；长期在线表述只作后续演进。


日期：2026-11-01。状态：目标设计、尚未实现。依据 PRD 十步学习闭环；本设计规定必要依赖、确认点和业务状态，Agent 的行动选择见 [Agent 运行设计](agent-runtime-design.md)。系统职责见 [产品系统设计](system-design.md)。

## 1. Workflow 的职责

Workflow 回答当前处于什么业务状态、哪些操作可以执行、什么结果能推进、什么需要用户确认。它不替 Agent 决定每一次搜索、解释和修订方式。
产品阶段和 Agent 运行状态分别记录：用户在“学习”阶段可以有多个已完成/暂停的 Agent run；一轮聊天可以处理多个动作，不等于一次完整学习会话。

## 2. 初始化依赖

| 节点 | 输入及产物 | 放行条件 |
|---|---|---|
| W1 目标澄清 | 目标、用途、范围、节奏/容量与偏好 | 用户确认目标理解；缺自评/期限不阻塞 |
| W2 建立目标资料 | 检索资料、来源、访问情况、适用能力 | 有真实可用依据；不足明确说明并补查，不能伪装检索完成 |
| W3 能力矩阵与起点测评 | 范围/标准确认、实际题目、提交、初始证据及未测范围 | 先确认矩阵再测评；有效结果形成可用于规划的画像，覆盖不足显式标注 |
| W4 生成滚动计划 | 目标/画像驱动的补充检索、路线图、近期安排与来源关联 | 输入与预算满足要求，生成待审版本 |
| W5 计划自审核 | 来源支持、画像匹配、标准与预算合理性 | 审核通过；失败退回 W4，来源不足可回到 W2 |
| W6 展示与确认 | 工具生成可读计划及审核说明 | 用户确认同一版本，计划才生效 |

这是必要依赖图，不是禁止往返的单行步骤列表。Agent 可在未满足依赖时补检索、追问或修订；不能跳过审核/确认。回到前一节点不默认抹掉其他仍有效记录，受输入变化影响的派生结果需标记过期。

## 3. 学习与周期闭环

| 节点 | 正常行为 | 状态保护 |
|---|---|---|
| W7 学习执行 | 从生效计划生成任务，讲解/提示，识别明确提交并按原标准判断 | 提问不算提交；结果先展示，用户确认验收后才按规则收尾/推进 |
| W8 会话收尾 | 保存摘要/接续点，按有效证据更新画像，按来源更新偏好 | 摘要不生成能力证据；失败可恢复，暂停或未完成不伪装通过 |
| W9 复习复验 | 候选排序、告知、计预算、逐知识点留证 | 每实际会话自动至多一个复验任务，16 小时保持条件与已有 PRD 一致 |
| W10 周期回顾 | 7 天根据真实表现决定保持/调整/新执行窗口 | 可返回时触发；新或改计划再经 W4～W6，不自动激活 |

里程碑/目标达成按用户确认的必需标准及独立证据规则判定，不按任务排完或周期结束判定；推进不等待保持复验。具体数值与证据条件以 PRD 为准。

## 4. 合法行动与确认

Workflow 查询接口通过 LearningRouter 返回获准的业务快照、当前缺口、允许行动类别、待确认对象及版本。实际确认凭据保留在可信执行上下文，不返回模型；其他领域的数据通过各自 Router 校验。执行复核接口在动作实际运行前重新验证；Agent 提议不能修改这份规则。
确认凭据绑定主体、Way、对象 ID、版本、操作和有效状态。修订计划后旧确认失效；拒绝、取消、未知或故障均不批准。确认偏好、任务结果或旧计划不等于批准新目标。
业务状态只能由业务命令处理器改变，并校验前置状态、当前版本和幂等身份。工具执行成功不等于事务保存成功，输出必须区分。

## 5. 中断与失败

不按无交互自动切会话；暂停/退出/中断保存最后可靠状态。业务阶段、用户提交、待确认状态与 Agent run 的暂停点分别保存，返回时确认可用时间后接续。
API 故障、模型无效结果、状态冲突、用户不会和用户拒绝分别处理。前三类不制造能力零分；有效的“用户不会”可作为未完成表现，用户拒绝不是学习失败。
调用重试仍按每逻辑调用含首次最多 5 次、总计 120 秒；不以此代替 ReAct 动作总数限制。迟到结果不应用，已经可靠保存的有效结果不回滚或重复应用。

## 6. 验证入口

从应用事件入口验证：未确认不能进入正式学习；审核失败不能激活；错配提交不能判定；同提交确认重放不重复推进；实质变更旧授权失效；中断不丢待办；回顾不无条件改计划。
不按具体工具调用顺序写死全部测试；多条合法探索轨迹只要守住依赖并产生合格结果都可接受。具体 Agent 动作选择质量另行评估。
