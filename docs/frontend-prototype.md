# 桌面交互原型 v0.1

日期：2026-11-01。状态：Figma 可点击初稿，待项目负责人逐步调整；不是已实现前端，也不代表学习闭环或模型效果通过验收。

[打开 Figma 设计](https://www.figma.com/design/cYMq5VW2JhRcTer0oopFjC?node-id=3-2)；[从首次使用开始演示](https://www.figma.com/proto/cYMq5VW2JhRcTer0oopFjC?node-id=3-2&starting-point-node-id=3%3A2)。Figma 中也设置了“首次使用”“日常学习”“复习与周期回顾”三个播放入口。

## 1. 本版范围

按当前 [PRD](PRD.md) 的初版功能设计，而非只复刻现有 CLI。采用 1280 × 800 桌面画面、左侧导航和中性浅色主题；当前只呈现一个学习路径，不设计多用户、多个 Way 切换或独立 Review Agent。

| 页面/流程 | 本版可查看与点击的内容 |
|---|---|
| 目标建立 | 示例目标、容量与节奏、两种讲解偏好切换，继续建立路径 |
| 资料与能力范围 | 来源与用途、能力点及标准，确认后进入测评 |
| 起点测评 | 综合任务、示例作答、“目前不会”反馈入口 |
| 计划 | 路线图、近期任务、时间、来源与自审核；确认或提出修改 |
| 学习任务 | 原题与标准、参考资料、提示、示例提交及暂停 |
| 任务结果与依据 | 标签页切换，逐项依据、原始提交、接受与异议入口 |
| 学习收尾与能力 | 已验收任务、独立表现、尚未验证的保持、未测范围分开显示 |
| 资料 | 来源链接、采用用途与正文取回状态 |
| 复习与复验 | 新会话与 16 小时间隔示例、新任务入口、跳过及预算说明 |
| 七天回顾 | 周期表现与调整理由；保留原计划或进入修改入口 |
| 暂停/恢复 | 最后保存点与接续入口 |
| 设置 | 模型/搜索配置状态、数据与诊断范围说明 |

共 14 个主页面（含复验任务），另有偏好、使用提示后的结果/证据/收尾等分支及反馈状态，共 23 个画面、146 个点击连接。页面数量包含演示状态，并非 23 个独立产品功能。

提示分支单独标记使用帮助，结果不计独立表现；任务完成不自动等于能力掌握。结果在用户接受前标记待确认。复验只展示新任务结构，不伪造一次保持成功。

## 2. 组件来源与后续代码映射

项目负责人指定使用 [shadcn/ui](https://ui.shadcn.com/docs/components/base/radio-group)，采用其 Base UI 路线。当前连接的 Figma 库未检索到匹配的 shadcn 组件，因此本稿是按网站规范建立的本地可编辑组件，不冒称官方库导入，也未将代码组件安装进项目。

| 原型元素 | 实现时选用的 shadcn/ui 组件 |
|---|---|
| 主要动作、次要动作 | Button 的 default / outline |
| 导航、内容分区 | Sidebar、Card、Separator |
| 目标、容量、作答 | Field、Label、Input、Textarea |
| 偏好与测评单选 | RadioGroup、RadioGroupItem；同组只允许一个选中 |
| 结果 / 证据切换 | Tabs |
| 配置缺项、未测、待确认 | Alert、Badge |
| 修改、争议、提示反馈 | 后续按具体交互选择 Dialog 或内容面板 |

中文字体采用 Noto Sans SC；本版为布局与交互初稿，不是与网站逐像素一致的成品主题。Figma 中重复控件使用组件实例，布局、文字和 token 可编辑，未用完整界面截图充当设计。

编码技术已同步到 [技术选型](technology-and-module-design.md)：React + TypeScript + shadcn/ui（Base UI）+ Tailwind CSS。界面通过 Electron 接入 Python 应用服务，不复制业务确认、证据生效和复验排序规则。

## 3. 演示边界与验证

- 全部学习内容、保存与配置状态都是示例；未联网、未调用模型、未访问用户真实学习数据。
- 这是 Figma 导航原型，不是运行中的 React 应用。输入框只展示示例，不能自由输入后获得真实判定；仅部分选项有切换演示。
- 修改计划、“目前不会”与异议目前展示反馈入口，未完整模拟所有业务分支；尚未覆盖超时、重连、配置修复、每种争议纠正与删除确认流程。
- 入口允许跳到不同演示场景，不能将它当作已实现的 Workflow 权限与阶段放行。
- 已检查连接目标、三条起点、各画面的文本边界、字体与可编辑节点；主学习页面完成截图审查并修正多行文字重叠。尚未逐个手工点击所有路径，也不将这些检查计为产品验收通过。

下一轮优先由项目负责人体验主线，确定页面信息密度、学习区是否需要独立对话面板，以及计划/证据的展示方式，再补完整交互与异常状态。
